# 0.2.2 最终需求核对

核对日期：2026-10-13。按最终指示执行，后来的指示覆盖前面的版本。

## 本轮直接修复

- 删除条目后留下的编辑草稿不再反复报“这条内容已被删除”。加载实际数据后，将孤立草稿转为新增，保留输入和附件，等待用户主动保存。
- 两类输入区的旧草稿、编辑中的无截止时间待办都补齐建议日期和分钟；“应用”关闭时仍不写截止时间。
- “数据与备份”显示 0.2.2 和运行方式，便于核对旧窗口。
- Windows 桌面入口可指定现有数据目录，并复用指向同一数据目录的本机服务，避免两个入口各自持有数据副本。
- 汇报导出按钮补入主按钮动画，关闭按钮补左右摆动。

## 0.2.2 补充

- 主输入区常驻清空按钮。保留应用开关、自动同步开关和工作记录发生日期/时间；待办开启应用时重置为当前分钟，关闭时留空，刷新仍留空。
- 清空包括正文、标题、项目、附件选择和关联项。编辑时退出编辑，不删除已保存条目。15 秒内可撤销；继续输入后不会被撤销覆盖。
- Windows 修正 200% 缩放下窗口实际只有 627×390 CSS 像素的问题；默认恢复为约 1267×815，并处理跨显示器 DPI 变化。
- Windows 启动改为引擎与服务并行初始化；无监听端口时不发失败的 HTTP 探测，子服务用就绪信号通知；已运行时直接激活窗口。
- 左上角、浏览器标签、Windows EXE 与安装包、Mac 图标资源统一为记录页图标。窗口名称为 Work Log，移除重复原生标题条。
- 清空功能 Chromium 与 WebKit 测试通过。原生桌面保存/PDF、草稿恢复及键盘操作回归另行执行。Mac 原生包仍需 GitHub Mac runner 构建验证。

- 调色盘：六种预设、自定义颜色、恢复默认、持久化，主按钮自动选择明暗文字；Chromium 与 WebKit 验证。Windows 应用与桌面快捷方式换色；Mac Dock 换色源码已接入，尚未原生测试。
- 时间线标题/搜索/日期区域由约 280 CSS 像素压缩至约 135 像素；导出按钮放到标题右侧，保留功能。任务卡片收紧，完成方框由 25×25 改为 14×14 CSS 像素，外围点击区域保留。

- 时间线相邻日期之间增加浅色虚线：竖排横向分隔、横排纵向分隔，同一天的任务保持紧凑。
