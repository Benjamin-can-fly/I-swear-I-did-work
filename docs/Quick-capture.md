# 随手记 · Quick capture

打开 Work Log，在「今日」「待办事项」或「工作记录」的 **随手记** 里直接写。三个入口都会根据内容判断去向，不用先选输入模式。「今日」和「待办事项」共用草稿；切换到「工作记录」可以另外起一段。

| 写下的话 | 保存后 |
| --- | --- |
| 每天晚上8：00钟记单词 | 建立“记单词”每日计划，每次截止时间为 20:00。当日勾完，次日会有新的一次。 |
| 每周写三篇日记 | 每周完成三次，哪天写都可以。 |
| 刚改完了组会 PPT。明天中午前发给王老师。 | 一条工作记录，加一条明天 12:00 截止的待办。 |
| 帮我记一下，我今天晚上八点截止，背单词 | 预览“今晚 20:00 · 背单词”。事项名称是“背单词”，今晚 20:00 单独存为截止时间。 |
| 今晚背单词 | 只记“今晚”，不设具体截止钟点；只写到“我今天晚上”还不会生成事项。 |
| 周五写报告 | 安排到周五，不设截止时间。 |
| 每周一到周五晚上八点背单词 | 只在工作日生成，周末不生成。 |
| 今天晚上21：00前要把csp作业补完然后把数学学了，还有seminar（优先级高） | 三条待办：补完 csp 作业、学数学、seminar；都在今天 21:00 截止，只有 seminar 标为高优先级。 |
| 明天9点开始整理资料，后天18点截止 | “整理资料”一条待办，分别保存开始安排和截止时间。 |
| 从11月6日开始每周写3篇日记，到11月30日结束 | 每周三次，起止日期分别为 11 月 6 日和 11 月 30 日；不替你指定哪天写。 |
| 每周写三篇日记，还有跑步两次 | 两个每周计划，分别完成三次、两次。 |
| 写完作文之后检查一遍 | “写作文 → 检查作文”，后一步等待前一步完成。 |

**停笔看预览，按 Enter 保存。** 点开预览中的一行，可以改去向、文字、优先级和时间，也可以选「不保存」。每条的修改会随草稿保留。计划先显示周期和次数或时刻；起止日期和提醒按需展开。需要填写项目或统一指定截止时间时再展开「选项」。Ctrl + Enter 换行，选中文输入法的候选词不会提交。一次保存里的多条结果可以一起撤销。

今日里没写日期的普通待办会留在今天；已经写了“明天”的安排不会被改成今天。已有计划在「今日 → 管理计划」修改，「待办事项 → 选项」也通向同一处。Windows 桌面版勾选「Windows 系统提醒」后会把具体时刻的提醒交给系统，应用退出后仍可提醒；每次打开补齐未来 30 个自然日内最近的 64 条提醒。系统勿扰或关机可能影响送达。浏览器和没有系统提醒支持的版本只在应用运行时提醒。

“刚把 PPT 发给王老师了”如果能明确对应一个已有待办，预览会显示完成该项。有多个相似待办时，需要点选对应的那一条。“如果……”或目前还不能表达的安排不会直接保存成一条新计划；原话保留在输入框里。

**English.** Write in Quick capture on Today, Tasks, or Journal. “Tomorrow at 9 pm finish homework and study mathematics, also review seminar (high priority)” becomes three tasks with a shared deadline; only seminar gets high priority. “Practice vocabulary every day at 8 pm” creates a daily plan. “Write in my journal three times a week” sets a weekly target without choosing the days for you. Expand a line to adjust its fields, press Enter to save, or use Ctrl + Enter for a new line.

## 后续任务

“先写作文，再检查一遍”“写完作文之后检查一遍”表示先后关系；单纯的“还有”表示独立事项。后续事项在前一步完成前显示为等待，不会提前提醒；勾完前一步会解锁并定位下一项。撤销前一步的完成，尚未完成的后续事项恢复等待，已经完成的历史不会自动改写。

点开预览，在“前一步”中调整关联；选“独立任务”取消等待。已保存的普通事项可通过三个点 → 修改 → 选项中的“完成哪一项后开始”调整。删除前一步后，未完成的后续事项会提示修改关联，不会擅自解锁。这一版支持普通待办的先后关系，周期计划之间暂不支持关联。

## 在线模型与离线记录

默认使用国内硅基流动提供的通义千问 Qwen3-8B，海外用户也可以选择 Gemini 2.5 Flash。模型都在线运行，不下载本地模型。首次使用展开“配置在线模型”，选择服务商并填写自己的 API 密钥。密钥只保存在自己的用户目录，不进入草稿或安装包。本次输入会发送给选定的服务商，全部历史日志不会发送；不会自动换服务商。免费额度、认证要求和限流以服务商账户为准，没有密钥时会明确提示。

断网才自动启用原有关键词识别和手动调整。在线模型错误或额度不足时保留输入并提示重试，不冒充识别成功。上述例子用于说明预期用途，模型输出仍需核对。
