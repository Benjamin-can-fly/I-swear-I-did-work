# Work Log 0.2.7 · 计划编辑调整

本次为本机试用版，尚未发布 GitHub 安装包。

## 原有功能保留

普通待办仍可填写内容、附件、项目、优先级、状态、开始与完成时间、关联记录，以及可选的截止时间；自动同步至工作记录、完成与撤回、日期检索、时间线、PDF 导出、备份和设置继续保留。

## 新的填写方式

在待办填写框的“安排方式”选择普通待办、每日计划、每周计划或每月计划。

- 只指定次数：设置每天／每周／每月完成几次。今日页合并显示进度，每勾一次完成一个独立事项。
- 指定时刻：点击“安排时间”，按需添加时刻。每日可一天多次，每周可选星期，每月可选日期或最后一天。同一天可有多个时刻。
- 默认提前 30 分钟出现在今日页，更多选项内可调整为 0–1440 分钟，并选择是否在应用运行时提醒。
- 月份没有所选日期时按该月最后一天安排。同一天同一时刻不重复生成。
- 已有计划在同一个填写框底部展开；今日页“管理计划”也可查看、修改、暂停或删除计划，没有增加侧栏页面。

普通待办的截止时间设置保留。计划使用安排时间，因此不同时显示普通待办的截止日期控件。开始、结束、提醒等低频设置放在更多选项里。

## 完成、编辑与历史

完成只影响当前那一次。次日／下周／下月会生成新的事项，已完成的历史不清空。每周以周一开始，每月按自然月计算。

修改计划默认更新尚未到时的安排；选中“同时更新本周期未完成的安排”可以一并调整本周期。已完成记录保留。切换日／周／月周期从下个周期生效。

暂停停止生成新的事项；已生成的任务继续保留。删除计划也保留已有任务和记录。单次任务可通过原来的菜单修改、跳过或删除。

关闭应用后不提醒。长时间未打开时不会补造每一天的任务；再次打开生成当前周期，之前已生成的未完成事项仍可查找。系统通知可能受系统通知设置影响。

## 本机回滚

关闭 Work Log 后，运行 `rollback/before-plans-20261017-012531/Rollback-to-0.2.6.cmd`。

恢复脚本先备份回滚当时的安装和数据，再恢复 0.2.6。它保留当前记录、任务和附件，暂停旧版不支持的新计划，防止旧版错误生成任务。不会用修改前的数据快照覆盖后来写下的内容。源码的修改前快照、稳定源码 ZIP 和安装备份都在同一目录内。

- Chromium 和 WebKit：完整计划编辑、提前显示、分次完成、同步撤回、草稿恢复、中英界面以及 800／390 像素宽布局。
- 今日页回归：附件、午夜切换、计划暂停恢复、普通待办与备份。
- Windows 原生：独立／复用后台两种启动方式，保存、主题、PDF、提醒消息桥接与关闭行为。
- 独立目录实测回滚：恢复旧可执行文件，保留新版本写下的任务、记录与附件。
