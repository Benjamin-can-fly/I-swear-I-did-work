# Work Log 使用说明

[下载 PDF 使用说明](../output/pdf/Work-Log-User-Guide.pdf) · [下载安装包](https://github.com/Benjamin-can-fly/I-swear-I-did-work/releases)

## 输入与保存

今日、待办事项和工作记录共用随手记操作方式。直接写完整的安排或已经完成的事情；联网且模型准备好时，整段原话会交给语言模型，生成事项、类型、日期、优先级与计划条件。模型只处理这次输入，不读取全部日志，也不会自行执行保存。

结果折叠在“查看/修改”中。先选择单次事项或周期计划，再核对日期、次数和其他设置。按 Enter 保存，Ctrl + Enter 换行，输入法选字不会提交。原话保留；误识别可以在保存前修改。需要等前一步完成才开始的任务，可以设置前一步。

使用在线 Gemini 2.5 Flash，不再下载或运行本地语言模型。首次使用展开输入框中的“配置 Gemini API 密钥”，填写自己的密钥。密钥只存在自己的用户目录，不进入草稿或安装包。这次输入会发送给 Google；模型不读取全部日志。免费额度、可用地区与限流以服务商为准，没有密钥时会明确提示。 可在 https://aistudio.google.com/apikey 获取密钥。

## 网络变化

无网络时自动使用离线记录：恢复原有关键词识别，允许手动调整字段。网络恢复后，新输入使用模型；已经手改的草稿保持原样。在线模型故障不会偷偷切成关键词结果并声称成功，可以保留输入后重试。

## 日常使用

- **今日**：今天的安排、计划和逾期提醒；点击已办、待办、已搁置数字查看明细。
- **待办事项**：勾选或点击文字完成，通过三个点修改、搁置、返回待处理或删除。已关联的后续任务在前一步完成后解锁。
- **工作记录**：保存做过的事、过程、结果、发生时间和附件。只有开启自动同步的待办会生成关联记录；独立记录不会反过来修改待办。
- **时间线**：合看过去记录和未来任务，按单条、天、周、月勾选，组合导出 PDF 汇报。
- **数据后台**：查看使用情况、完成与漏做情况；逾期为红色，24 小时内到期为黄色。
- **设置**：更改主题色、深浅模式与中英文。
- **数据与备份**：导出包含附件的备份，或主动导入自己的备份。批量删除和完成操作可按界面提示撤销。

## 发给别人

Windows 发送 windows-x64-setup.exe。Mac 按“关于本机”中的芯片选择 arm64（Apple M 系列）或 x64（Intel）的 .pkg。也可以只发 GitHub Release 链接和本说明，对方无需源码或你的数据目录。

每个新用户从空白数据和默认设置开始。升级会继续使用自己原来的数据；安装包不包含开发者个人数据。请勿把个人 JSON 备份、附件目录或浏览器配置发给朋友当安装包。

当前安装包尚未完成发布者签名或 Apple 公证。确认来源后按操作系统说明处理首次打开提示，不要关闭系统安全保护。模型识别不是准确性保证，重要安排请检查字段后保存。
