# 网络语言模型

随手记把整段原话直接交给 **Gemini 2.5 Flash**，由模型理解事项、已办或待办、周期、次数、时间、优先级和先后关系。软件校验返回字段，再显示可编辑的预览。在线模式不再先用关键词拆分原话，也不再启动或下载本地大模型。

## 配置

在随手记的“配置 Gemini”入口填写自己的 Google AI Studio API 密钥。密钥只保存在当前用户目录的 `WorkJournal/capture-provider.json`：Windows 使用 `%LOCALAPPDATA%`，Mac 使用 `~/Library/Application Support`。它不属于日志数据、备份或发布包，接口也不会把密钥返回浏览器。部署环境可使用 `GEMINI_API_KEY`。

Google 提供的免费层有地区和额度限制，需要用户自己的密钥；软件没有共享公共密钥，也不会在额度用完后偷偷切换服务。免费额度用完会明确提示。若项目自行开启计费，实际费用由 Google 的项目设置决定。

## 使用方式

输入“我每周写一次作文”，模型应返回“写作文”、每周、1 次；输入“写完作文再检查一遍”，应返回两项及先后关系。时间、计划次数等仍可在预览选项里修改。原话保留，不会自动删除。

有网且密钥已配置时使用网络模型。断网后自动转为关键词辅助和手动编辑；网络恢复后回到模型。在线时如果密钥无效、额度耗尽或模型请求失败，会保留原文并显示错误，不把关键词结果冒充成模型结果。

正文会发送给 Google 处理，附件和整个日志库不会随此次解析上传。请求使用系统代理，最长等待 25 秒；软件启动不会等待模型加载。
