# 在线模型：国内与海外

随手记将整段输入交给语言模型，填入事项、日期、优先级、周期、次数及前后关系。字段仍可修改，保存由用户决定。

## 首次配置

展开随手记中的“配置在线模型”，选择服务商并输入自己的 API 密钥。

- **硅基流动 · 通义千问 Qwen3-8B（国内）**：新用户默认选项，使用国内接口，关闭深度思考。到 https://cloud.siliconflow.cn/account/ak 创建密钥。免费模型的可用性、认证要求和限流以服务商当前账户与定价为准。
- **Gemini 2.5 Flash（海外）**：保留原有配置，到 https://aistudio.google.com/apikey 创建密钥。可用地区、免费额度与计费由 Google 管理。

选择后不会自动换服务商，也不会在额度不足时切换付费模型。切换服务商须输入对应服务商的密钥，已有 Gemini 密钥不会发送给硅基流动。

## 数据与网络

本次输入会发送给选定的服务商；附件和整个日志库不会随解析上传。密钥只保存在本机用户目录的 WorkJournal/capture-provider.json，不属于日志备份或发布包，接口不会将密钥返回浏览器。Windows 使用 LOCALAPPDATA，Mac 使用 Library/Application Support。

国内模型直接连接国内接口；海外接口沿用系统代理配置。网络检测包含国内站点。确认断网才自动启用关键词识别及手动调整；在线密钥无效、额度不足或接口报错会明确提示并保留输入。

部署环境支持 SILICONFLOW_API_KEY 或 GEMINI_API_KEY；不要将密钥写入公开项目。模型无需本地下载，也没有本地推理常驻进程。

## 示例与限制

“每周写一次作文”对应事项“写作文”、每周、一次；“写完作文再检查”对应两项和前后关系。重复设置排在时间设置之前，同一条普通待办保留一个截止日期入口。

此次按要求没有进行真实云模型调用测试，尚无个人密钥。接口代码完成不等于识别准确率和响应速度已经验证。25 秒是请求超时上限，不是承诺每次需要等待的时间。
