# Work Log 0.2.8 · 界面简化

本机试用版。此次调整不改变任务、记录或计划的数据格式。

## 常用入口

工作记录与待办的填写框默认只显示正文、附件、选项和保存。右上角的小字提示当前时间设置，叉号仍用于清空当前输入。Enter 保存，Ctrl + Enter 换行。

日期、时间、同步、项目、关联和其他附加信息均在“选项”内。每日／每周／每月计划也在这里；选择周期与次数即可保存，具体时刻可不设置。编辑已有计划会自动展开选项。关闭选项不会丢失填写内容。

## 各页变化

- 今日保留一处新增入口、文字进度和计划区域，移除重复标题与空状态里的重复按钮。
- 工作记录的汇总与近期待办收成一个折叠区域，记录列表使用完整宽度。
- 待办保留待处理／已搁置／已完成筛选。日／周／月与全部日期集中在一个选择框中。
- 时间线将月份、左右切换和今天放在同一行；横向／纵向改为一个选择框，汇报导出仍在右上角。
- 数据后台优先展示指标与图表。数据明细、统计口径和说明按需展开，编辑、导入与导出仍可使用。
- 设置仍是完整页面。统一外观、主题色与语言分区，自选色值收起，常用颜色保留直达。
- 日期检索改用“事件列表／月历”，定位与排序单独展开；备份保留主要导入导出，Markdown 放在其他导出格式内。

## 回滚

关闭 Work Log 后运行：

`rollback/before-compact-20261017-025106/Rollback-to-0.2.7.cmd`

恢复脚本会先备份恢复当时的安装与数据，再恢复旧界面。当前数据文件不会被旧快照覆盖，0.2.7 支持现有计划数据。修改前源码也在同一目录的 `source` 中；恢复桌面界面不会覆盖开发中的源码。
