# Work Log 0.2.13 发布说明与验证边界

最终方案为国内硅基流动 Qwen3-8B 与可选 Gemini 2.5 Flash 在线接口，移除本地模型运行和下载安装入口。根据最新要求，最后这次云端改动没有重新运行测试，也未提供真实 API 密钥进行联通验收。不能把此前本地方案的通过结果视为云端识别效果证明。

此前隔离环境曾验证统一输入、离线关键词记录、草稿、附件、同步与撤销，以及新用户为空数据。这些属于改动过程中的验证，不是最终版本的完整回归保证。

发布只复制程序源码和使用说明，压包前检查日志、计划、附件、使用记录、模型文件、密钥和浏览器配置没有进入发布目录。每个用户的 在线模型 API 密钥保存在用户目录，不进入公开代码。GitHub 构建状态和 Release 实际资产是安装包完成与否的依据。

在线模型需要各用户配置自己的密钥，输入会发送给用户选择的服务商。免费额度与地区可用性以服务商为准；网络故障、额度不足和无效返回保留输入并明确报错。无网络自动启用关键词识别和手动调整。

本次不提供云同步、账号登录或自动更新服务；安装包尚无 Windows 发布者签名或 Apple 公证。
