# Work Log 0.2.13

- 随手记统一为一个输入入口。联网且模型就绪时，整段原话交给语言模型生成事项及字段。
- 无网络时自动切换到关键词识别与手动调整，保留原话和草稿；恢复联网不会覆盖手动修正。
- 结果收为“查看/修改”，选项按周期、时间和附加信息排列，减少重复的截止日期入口。
- 任务支持前置关系，完成前一步后定位下一步；支持周期计划、附件、同步记录及 PDF 汇报。
- 新增发布包隐私检查，新安装从空数据与默认外观开始。升级仍保留使用者自己的数据。

请下载与你的系统匹配的安装包，并阅读随附的 **Work-Log-User-Guide.pdf**。

默认使用国内硅基流动提供的通义千问 Qwen3-8B，海外用户也可以选择 Gemini 2.5 Flash。模型都在线运行，不下载本地模型。首次使用展开“配置在线模型”，选择服务商并填写自己的 API 密钥。密钥只保存在自己的用户目录，不进入草稿或安装包。本次输入会发送给选定的服务商，全部历史日志不会发送；不会自动换服务商。免费额度、认证要求和限流以服务商账户为准，没有密钥时会明确提示。 未完成发布者签名与 Apple 公证。

此次在线接口改动应用户要求未重新运行测试；此前本地模型测试结果不代表这一版云端效果。

安装包不含开发者的日志、计划、附件、缓存或个人配置。发送软件时不需要发送个人备份。
